Introduction to logic circuit ICs

An integrated circuit (IC) packs several logic gates into one chip. The common 74xx (TTL) series chips below are all 14-pin: pin 14 is VCC (+5 V) and pin 7 is GND.

ICGateGates per chipOutput

7408AND4Y = A · B
7432OR4Y = A + B
7400NAND4Y = (A · B)'
7402NOR4Y = (A + B)'
